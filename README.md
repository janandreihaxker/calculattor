## Run in VS Code

1. Open this folder in VS Code.
2. Open the terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the localhost link shown by Vite.

## Build for deployment

```bash
npm run build
```

This project is ready to push to GitHub and deploy on Vercel.
